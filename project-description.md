# Project Description

I built the PHHS Hack Club website as a full-stack platform for both the public-facing club site and the internal tools our members need to actually share their work. Instead of making a simple informational website, I wanted this project to function as a real system for the club. The site includes public pages like the homepage, about page, events page, gallery, members page, donate page, contact page, and a coding-hours leaderboard, but it also includes a full member portal and admin dashboard behind authentication.

On the public side, the website is designed to explain what PHHS Hack Club is, when we meet, what kinds of things students build, and why someone should join even if they have no prior experience. Visitors can browse approved student projects in the gallery, view detailed project pages with screenshots and writeups, look through the members page, and use the contact form to reach the club. I also added a leaderboard page that uses Hackatime data so members can see coding activity over time in a way that makes the club feel more alive and community-driven.

For members, I built a protected portal where students can sign in using Hack Club OAuth. After signing in, members can create projects, write devlogs, upload images, and save drafts before submitting their work for approval. Projects support descriptions, links, tags, screenshots, and Hackatime project connections so coding hours can appear on public project pages. Devlogs let members document progress over time instead of only showing a final result, which makes the site better at reflecting how people actually build things. I also implemented Markdown-based writing tools so project writeups and devlogs are easy to format without requiring a complicated editor.

One feature I cared about a lot was making the workflow practical, not just technically functional. Because of that, I included draft states, submission states, and autosaving for project work so members do not lose progress while editing. Image uploads are handled through object storage, which makes it possible to attach screenshots to projects and devlogs in a scalable way. I also added profile picture support for members, which helps the site feel more personal and gives the club a stronger sense of identity.

For club leadership, I built an admin side of the site so the website can be managed without directly touching the database. Admins can review pending verification requests, approve or reject submitted projects and devlogs, and manage member information and roles. This makes the platform usable as an actual club operations tool instead of just a portfolio site.

From a technical standpoint, I built the site using Next.js, React, and TypeScript, with Prisma and PostgreSQL for the database layer and MinIO for file storage. Authentication is handled with Hack Club OAuth and JWT-based session cookies. I also integrated SMTP email sending for the contact form and Hackatime OAuth/data fetching for coding-hour features. Overall, the goal of the project was to create something that feels polished for visitors, useful for members, and sustainable for club leadership to run over time.
